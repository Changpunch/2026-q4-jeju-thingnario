## 使用方式

1. 打開網址，輸入濟州島的密碼。勾選「記住我（30 天內免再輸入）」，之後 30 天內不用再輸入。
2. 第一次進來會出現頭像選擇畫面：左右滑動找到自己的頭像，點一下就登入。之後網頁會記住你是誰，不會再跳出來。
3. 想換人，點右上角自己的頭像。

**打開後會先看到哪一頁**（依韓國時間自動判斷）：

| 時間 | 打開後直接進入 |
|---|---|
| 出發前 | 無腦跟玩 → 今天（出發倒數、行前待辦） |
| 旅途中（11/6–11/8） | 無腦跟玩 → 今天（現在、下一站） |
| 回國後（11/9 起） | 分帳 → 結算 |

> 想預覽旅途中的樣子，可以在網址後面加 `?now=2026-11-07T11:20%2B09:00`，網頁會假裝現在是 11/7 11:20（韓國時間）。

手機、電腦都可以看（RWD）。手機上最上方是一行精簡標題列，電腦上保留完整的大標題。

### 「今天」頁在旅途中的判斷規則

- **現在**：開始時間已經到、還沒到下一項的那一站；有填停留時間的話，會顯示還剩幾分鐘。
- **下一站**：下一個有時間的景點或活動（移動不算），並顯示中間的車程。
- 11/6 清晨 06:05 以前顯示「飛往濟州中」。
- 當天最後一站之後，顯示「今天的行程都結束了」和明天的第一站。
- 時間寫成「待定」「上午」這種無法判斷的項目，不會被當成現在或下一站。
- 每分鐘自動更新，不用重新整理。

### 行程詳情的「現在」指示線

旅途中看「今天那一天」的行程時，會出現橘色的「現在 HH:MM」線；已經結束的行程變淡、目前這一站加橘框，切換到行程詳情時會自動捲到現在的位置。編輯模式下不顯示。

### 編輯行程

1. 行程詳情右上角按「✎ 編輯行程」。
2. 每一項都可以「✎ 編輯」或用 ↑↓ 調整順序；兩項之間按「＋ 在這裡插入一項」可以新增。
3. 可以修改的欄位：
   - 類型（景點／活動、移動、航班、待討論）、哪一天、時間
   - 標題、停留時間、地點名稱、Naver 地圖連結
   - 說明、備註（橘色框）、參考連結、團體用餐（已訂位）
   - 地圖位置：在編輯視窗的小地圖上點一下，就是大地圖上的標記
4. 刪除要按兩次才會真的刪掉。
5. 按「完成編輯」離開編輯模式。

改完會直接存進 Google 試算表，其他人重新整理就會看到，**不需要重新上傳網頁**。

## 運作方式

```
GitHub Pages（index.html，StatiCrypt 加密）
        │  輸入密碼後在瀏覽器解密
        ▼
   行程網頁（純前端 HTML／CSS／JS，單一檔案，頭像與地圖圖片內嵌）
        │  行程、分帳讀寫
        ▼
Google Apps Script（網頁應用程式 API）
        │
        ▼
Google 試算表
  ├─ 行程-網頁        行程（網頁可編輯）
  ├─ Expenses-明細    花費與還款
  └─ Expense-設定     韓幣匯率
```

- **網站代管**：GitHub Pages，免費。
- **密碼保護**：[StatiCrypt](https://github.com/robinmoisson/staticrypt) 把整個網頁加密，repo 裡只有亂碼，輸入正確密碼才會在瀏覽器裡解開。另外加了 `noindex`，搜尋引擎不會收錄。
- **資料**：行程和帳目都存在組長的 Google 試算表，透過 Apps Script 讓網頁讀寫。網頁也會記住最後一次讀到的行程，暫時沒網路時仍可瀏覽。
- **費用**：全部免費。

## 從 0 開始架設

### 1. 建 GitHub repo 並開啟 Pages

1. GitHub 右上角 **+ → New repository**，命名後選 **Public**，勾選 Add a README → Create。
   - 免費版 GitHub Pages 只支援 Public repo，所以網頁才要加密。
2. **Add file → Upload files**，上傳 `index.html` → **Commit changes**。
3. **Settings → Pages**：Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)` → **Save**。
4. 等 1–2 分鐘，網址會出現在同一頁：`https://<帳號>.github.io/<repo 名稱>/`。

### 2. 準備 Google 試算表

**「Expenses-明細」分頁**（記帳），第一列標題如下：

| 日期 | 項目 | 幣值 | 總花費 | 墊付人 | 攤分人 | 類型 | 備註 | ID |
|---|---|---|---|---|---|---|---|---|
| 10/13 | 機票 | NTD | 87424 | Sonia | Sonia, Jubi, Mia, … | 支出 | | （自動產生） |

- **幣值**：`NTD` 或 `KRW`
- **攤分人**：用逗號分隔名字
- **類型**：`支出` 或 `還款`（還款＝墊付人把錢還給攤分人）
- **ID**：由程式自動產生，請不要手動修改

**「行程-網頁」分頁**（行程）不用自己建立。網頁第一次連上 Apps Script 時，會自動建立這個分頁，並把網頁內建的行程匯入。欄位如下：

| ID | Day | 排序 | 類型 | 時間 | 停留 | 標題 | 地點 | 地圖連結 | 說明 | 備註 | 參考連結 | 團體用餐 | 地圖X | 地圖Y |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

- **類型**：`景點`、`移動`、`航班`、`待討論`
- **排序**：同一天內由小到大排列（網頁上用 ↑↓ 調整即可）
- **地圖X／地圖Y**：大地圖底圖上的位置（建議在網頁上點地圖設定）

### 3. 安裝 Apps Script（API）

1. 在試算表選單 **擴充功能 → Apps Script**。
2. 刪掉預設內容，貼上 API 程式碼（存放在組長那邊，不放在這個 repo）→ 儲存。
3. 上方函式選 **setup** → **執行** → 依指示授權（只有第一次需要）。
   - 出現「Google 尚未驗證這個應用程式」時，點 **進階 → 前往（不安全）→ 允許**。
   - setup 會整理記帳欄位、補上 ID，並建立「Expense-設定」分頁（B1 為韓幣匯率）。
4. **部署 → 新增部署作業** → 類型選 **網頁應用程式**。
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 複製「網頁應用程式網址」，放進網頁原始檔後重新加密。

> 這支程式只會讀寫「行程-網頁」「Expenses-明細」「Expense-設定」三個分頁，不會碰試算表裡的其他分頁。

### 4. 加密網頁

使用 StatiCrypt 3.5.4，每次都沿用同一組 salt 和設定，大家勾過的「記住我」才不會失效：

```bash
npx staticrypt@3.5.4 index.html -p "<密碼>" --short --remember 30 --salt "<固定的 salt>" -d out
```

加密後在 `<head>` 補上：

```html
<meta name="robots" content="noindex,nofollow">
```

再把 `out/index.html` 上傳到 repo。

## 日常更新

### 行程有改

直接在網頁「行程詳情 → ✎ 編輯行程」修改，或直接改試算表的「行程-網頁」分頁。大家重新整理就會看到，**不用重新上傳網頁**。

> 原本手動整理的「Schedule」分頁已經不會再同步到網頁，請以「行程-網頁」分頁為準。

### 記帳

直接在網頁「分帳 → 明細」新增或修改，旅途中也可以在「今天」頁按「＋ 快速記一筆」（預設韓幣、全員分攤）。直接改試算表也可以，網頁按「重新整理」就會同步。

### 網頁版面或功能有改（需要重新上傳）

1. 請 Claude 更新網頁原始檔，並用同一組密碼重新加密。
2. 到 GitHub **Add file → Upload files**，上傳新的 `index.html` → **Commit changes**。
3. 等 1–2 分鐘，大家重新整理就會看到新版。

> 上傳前務必確認檔名是 `index.html`。如果電腦自動改名成 `index_1.html`、`index (1).html`，網站不會更新。這時到 GitHub 先刪掉舊的 `index.html`，再點新檔 → 鉛筆圖示 → 把檔名改回 `index.html`。

### 修改 Apps Script 程式後

要用 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署**。
不要按「新增部署作業」，否則網址會改變，網頁就連不上了。

### 確認有沒有上線成功

repo 首頁右側 **Deployments → github-pages** 出現綠色勾勾，就代表部署完成。若看到的還是舊版，請下拉重新整理，或關掉分頁再開一次。

## 分帳規則

- **匯率**：韓幣依「Expense-設定」B1 的匯率換成台幣，再一起結算（可在結算頁修改）。
- **公司補助**：慧景科技每人補助 NT$2,000，由組長 Sonia 統一領取（共 NT$16,000）。
  - 結算時已從每個人的分擔中各扣 NT$2,000，所以 Sonia 應收的金額會相對減少，大家不需要另外領回。
  - 讀到試算表資料之前不會顯示任何金額；每人最多折抵到自己的分擔額。
  - 說明收在結算頁標題旁的 ⓘ。
- **結算**：自動算出最少的轉帳次數。對方還錢後按「已還款」，會自動新增一筆類型為「還款」的紀錄，可以只還一部分。
- **誰的錢包在哭泣**：計算每個人「分到的花費」，不含還款，也不是先墊付的金額。
  - 分類依項目名稱自動判斷：交通、住宿、餐飲、網路通訊、門票玩樂、購物、醫美、其他。
  - 排行榜大家都看得到彼此的花費。
- 試算表裡的 `WT` 在網頁上顯示為 Wanting。

## 隱私與安全

這個 repo 是公開的，請不要放：

- 未加密的網頁原始檔
- 網頁密碼
- Apps Script 網址與驗證碼
- 試算表連結（試算表裡有護照資料）
- 訂位代號、電子機票號碼、租車確認編號、個人電話或 email

網頁本身也刻意不顯示訂位代號、機票號碼等資料，請以群組裡的 PDF 為準。
