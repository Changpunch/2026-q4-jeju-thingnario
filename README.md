## 網站有什麼

進入網頁 → 輸入密碼 → 選自己的頭像登入（右上角頭像可隨時切換）。

| 大分類 | 分頁 | 內容 |
|---|---|---|
| 交通住宿 | 機票 | 去回程航班、集合時間、行李額度 |
| | 住宿 | 民宿照片、入住 16:00／退房 10:00、房型、設備、導航 |
| | 租車 | 車型、取還車時間、機場接駁搭乘方式、駕照規定、押金與保險 |
| 無腦跟玩 | 旅遊大地圖 | 以 Naver 地圖截圖為底圖標出每一站，附濟州島小百科 |
| | 行程詳情 | 三天的時間軸，每站都有備註與 Naver 導航按鈕 |
| 自己帶腦 | — | 單獨行動規則、用餐集合時間、公司補助、出發前檢查清單 |
| 分帳 | 明細 | 所有花費，可直接新增、編輯、刪除（存回 Google 試算表） |
| | 結算 | 誰要給誰多少錢（最少轉帳次數），還錢後按「已還款」 |
| | 誰的錢包在哭泣 | 自己的花費總額＋分類圓餅圖、全員消費排行 |

其他小功能：

- 手機、電腦都能看（RWD）
- 出發前檢查清單的打勾、選過的頭像，只存在各自的手機上
- 旅程期間打開網頁，會直接跳到當天行程

## 運作方式

```
GitHub Pages（index.html，StatiCrypt 加密）
        │  輸入密碼後在瀏覽器解密
        ▼
   行程網頁（純前端 HTML／CSS／JS，單一檔案）
        │  分帳頁讀寫
        ▼
Google Apps Script（網頁應用程式 API）
        │
        ▼
Google 試算表（只讀寫「Expenses-明細」「Expense-設定」兩個分頁）
```

- **網站代管**：GitHub Pages，免費。
- **密碼保護**：[StatiCrypt](https://github.com/robinmoisson/staticrypt) 把整個網頁加密，repo 裡只有亂碼，輸入正確密碼才會在瀏覽器裡解開。另外加了 `noindex`，搜尋引擎不會收錄。
- **記帳資料**：存在組長的 Google 試算表，透過 Apps Script 讓網頁新增、修改、刪除。
- **費用**：全部免費。

## 從 0 開始架設

### 1. 建 GitHub repo 並開啟 Pages

1. GitHub 右上角 **+ → New repository**，命名後選 **Public**，勾選 Add a README → Create。
   - 免費版 GitHub Pages 只支援 Public repo，所以網頁才要加密。
2. **Add file → Upload files**，上傳 `index.html` → **Commit changes**。
3. **Settings → Pages**：Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)` → **Save**。
4. 等 1–2 分鐘，網址會出現在同一頁：`https://<帳號>.github.io/<repo 名稱>/`。

### 2. 準備 Google 試算表

試算表裡要有一個「Expenses-明細」分頁，第一列標題如下：

| 日期 | 項目 | 幣值 | 總花費 | 墊付人 | 攤分人 | 類型 | 備註 | ID |
|---|---|---|---|---|---|---|---|---|
| 10/13 | 機票 | NTD | 87424 | Sonia | Sonia, Jubi, Mia, … | 支出 | | （自動產生） |

- **幣值**：`NTD` 或 `KRW`
- **攤分人**：用逗號分隔名字
- **類型**：`支出` 或 `還款`（還款＝墊付人把錢還給攤分人）
- **ID**：由程式自動產生，請不要手動修改

### 3. 安裝 Apps Script（記帳 API）

1. 在試算表選單 **擴充功能 → Apps Script**。
2. 刪掉預設內容，貼上記帳 API 程式碼（存放在組長那邊，不放在這個 repo）→ 儲存。
3. 上方函式選 **setup** → **執行** → 依指示授權。
   - 出現「Google 尚未驗證這個應用程式」時，點 **進階 → 前往（不安全）→ 允許**。
   - setup 會整理欄位、補上 ID，並建立「Expense-設定」分頁（B1 為韓幣匯率）。
4. **部署 → 新增部署作業** → 類型選 **網頁應用程式**。
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 複製「網頁應用程式網址」，放進網頁原始檔後重新加密。

> 這支程式只會讀寫記帳的兩個分頁，不會碰試算表裡的其他分頁。

### 4. 加密網頁

使用 StatiCrypt 3.5.4，每次都沿用同一組 salt，大家勾過的「記住我」才不會失效：

```bash
npx staticrypt@3.5.4 index.html -p "<密碼>" --short --remember 30 --salt "<固定的 salt>" -d out
```

加密後在 `<head>` 補上：

```html
<meta name="robots" content="noindex,nofollow">
```

再把 `out/index.html` 上傳到 repo。

## 日常更新

### 行程有改（例如改時間）

1. 先改 Google 試算表的 Schedule 分頁。
2. 請 Claude 依試算表更新網頁原始檔，並用同一組密碼重新加密。
3. 到 GitHub **Add file → Upload files**，上傳新的 `index.html` → **Commit changes**。
4. 等 1–2 分鐘，大家重新整理就會看到新版。

> 上傳前務必確認檔名是 `index.html`。如果電腦自動改名成 `index_1.html`、`index (1).html`，網站不會更新。這時到 GitHub 點該檔 → 鉛筆圖示 → 把檔名改回 `index.html`（舊的那個要先刪掉）。

### 記帳

直接在網頁「分帳 → 明細」新增或修改，或直接改試算表，網頁按「重新整理」就會同步，不需要重新上傳網頁。

### 修改 Apps Script 程式後

要用 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署**。
不要按「新增部署作業」，否則網址會改變，網頁就連不上了。

### 確認有沒有上線成功

repo 首頁右側 **Deployments → github-pages** 出現綠色勾勾，就代表部署完成。

## 分帳規則

- 韓幣依「Expense-設定」B1 的匯率換成台幣，再一起結算（可在結算頁修改）。
- **公司補助**：慧景科技每人補助 NT$2,000，由組長 Sonia 統一領取（共 NT$16,000）。結算時已從每個人的分擔中各扣 NT$2,000，所以 Sonia 應收的金額會相對減少，大家不需要另外領回。
  - 讀到試算表資料之前不會顯示任何金額；每人最多折抵到自己的分擔額。
- **結算**：自動算出最少的轉帳次數。對方還錢後按「已還款」，會自動新增一筆類型為「還款」的紀錄，可以只還一部分。
- **誰的錢包在哭泣**：計算每個人「分到的花費」，不含還款；分類依項目名稱自動判斷（交通、住宿、餐飲、網路通訊、門票玩樂、購物、醫美、其他）。
- 試算表裡的 `WT` 在網頁上顯示為 Wanting。

## 隱私與安全

這個 repo 是公開的，請不要放：

- 未加密的網頁原始檔
- 網頁密碼
- Apps Script 網址與驗證碼
- 試算表連結（試算表裡有護照資料）
- 訂位代號、電子機票號碼、租車確認編號、個人電話或 email

網頁本身也刻意不顯示訂位代號、機票號碼等資料，請以群組裡的 PDF 為準。
